# 微信公众号草稿同步

工作台调用文章同步助手扩展，使用同一浏览器已登录的公众号。无需独立后端或公众号开发者凭据。当前只写入微信公众号草稿，不请求发布或群发。

## 参考接口

已核对 Wechatsync 当前默认分支 v2（扩展 manifest 版本 2.0.9）：

- [项目与安装说明](https://github.com/wechatsync/Wechatsync/tree/v2)
- [网页注入 API](https://github.com/wechatsync/Wechatsync/blob/v2/packages/extension/public/inject-api.js)
- [网页与扩展通信](https://github.com/wechatsync/Wechatsync/blob/v2/packages/extension/src/content/api.ts)
- [公众号适配器](https://github.com/wechatsync/Wechatsync/blob/v2/packages/core/src/adapters/platforms/weixin.ts)
- [扩展消息处理](https://github.com/wechatsync/Wechatsync/blob/v2/packages/extension/src/background/index.ts)

本项目独立实现调用层，使用已安装扩展提供的 `$syncer` / `$poster`，不下载或执行 CDN SDK，不将上游实现打包到工作台。

## 流程

1. `getAccounts(callback)` 获取登录状态，仅展示 `type === 'weixin'` 的账号。扩展会检查多个平台，首次检测可能需要几十秒。
2. 提交前通过 `magicCall({ methodName: 'checkAuth', account }, callback)` 重新核对账号，防止登录过期或用户已切换公众号。
3. 将当前图文渲染为带行内样式的 HTML，标题单独传递。本地图片读取为 base64 数据，消除只能在工作台使用的 blob URL。代码在提交前转换为同一代码框内的逐行富文本段落，避免编辑器将 `<pre>` 中的普通换行合并。用不换行空格保留空格及 Tab（按 4 列制表位展开），用不可见标记保留空行；保留语法高亮、强调行和单块换行设置。这一步只处理同步副本，不改本地文章、复制或下载内容，也不会猜测源文中已经丢失的换行。
4. 通过 `uploadImage({ src, account }, callback)` 逐张上传，替换为经过域名检查的微信图片地址。同一来源只上传一次。任何图片失败都会阻止提交草稿，保留本地原文。已经上传的图片可能留在公众号素材库，重试不保证复用素材。
5. `addTask({ guid, post, accounts: [account], draftOnly: true }, onUpdate, callback)` 创建任务。目标限制为公众号，v2 公众号适配器通过 `operate_appmsg` 的 `sub=create` / `type=77` 保存草稿；此操作新建草稿，不覆盖历史草稿。
6. 接收状态更新，只有目标账号明确返回 `status: 'done'` 才显示成功。第三个回调可能不触发，即使返回“排队中”也不算成功。超时记为待确认，不自动重试。

## 本地数据与失败处理

- IndexedDB 从 v1 升级为 v2，原文章及图片保留，新增独立 `syncRecords` 表。
- 同步开始前记录尝试，避免刷新页面后把未确认任务误认为从未发送；进度写入排队，防止旧进度覆盖最终结果。
- 登录信息由扩展处理，工作台不读取或保存 Cookie。成功链接只允许公众号的草稿编辑地址；持久化时移除会话 token 等参数，完整编辑链接仅保留在当前页面内存中。
- 如页面已刷新，不带 token 的旧链接可能需要重新进入公众号后台定位对应草稿。
- 成功后再点同步，会新建另一份草稿。记录对应同步时的快照，后续编辑不会自动更新远端内容。
- 封面、作者、摘要等字段在公众号后台补充；扩展可能按平台规则移除外链、调整部分样式。

## 验证范围

自动测试覆盖：标题/正文校验，扩展检测，只选择公众号，登录过期与账号切换，图片去重/上传失败，排版与图片替换，代码换行/缩进/空行/高亮及长命令，模拟编辑器清理空白后的实际浏览器显示，提交确认与成功状态的区别，并发拦截，超时/刷新后的待确认记录，记录不保存 token，v1 数据库迁移及手机布局。

浏览器测试模拟扩展的公开回调协议，不访问真实账号、不写入公众号。真实验收需要用户安装扩展并登录后，用一篇带图文章同步，打开后台核对草稿、图片和样式。微信登录态和后台接口受平台变动影响，模拟测试不能证明真实账号可写入。
